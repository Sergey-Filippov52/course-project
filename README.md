# Шахматы с волшебниками: консольная игра для двух игроков

## Описание проекта

Проект представляет собой консольное приложение на C++, реализующее вариант шахмат
на доске 8×10 с нейтральными волшебниками и магическими артефактами. Целевая
аудитория — пользователи, которым интересна классическая игра в шахматы с новыми
правилами и автоматическим соблюдением всех ограничений.

## Игровой процесс

* **Старт:** игроки по очереди делают ходы на доске 8×10.
* **Волшебники:** после каждого хода игрока два волшебника сдвигаются на одну клетку
по своим горизонталям, уничтожают всё на новой клетке (кроме артефакта усиления)
и оставляют артефакт на покинутой клетке через раз. Дойдя до края, разворачиваются.
* **Артефакты:** игроки подбирают артефакты и тратят на них ману. Виды: щит, обмен,
усиление, источник, телепорт.
* **Проверка хода:** программа проверяет, что ход допустим для выбранной фигуры
с учётом всех правил.
* **Особые ситуации:** шах, мат, пат, рокировка, взятие на проходе, превращение пешки.
* **Окончание партии:** победа возможна только после того, как волшебники побеждены
и сопернику поставлен мат. Если мат или пат случился раньше — побеждают волшебники.

## Лабораторная №2: классы Piece, Board, Game

В этой лабораторной реализованы три класса.

**Piece** описывает одну шахматную фигуру: тип, цвет, координаты и признак щита.
Проверяет правила: щит нельзя наложить на короля, щит нельзя наложить дважды.

**Board** хранит игровое поле 8×10 и ссылки на фигуры. Проверяет правила: нельзя
занять уже занятую клетку, нельзя поставить фигуру за пределами доски.

**Game** управляет ходом партии: игроками, волшебниками, проверкой победы.
Проверяет правило: победу нельзя объявить, пока волшебники живы.

## Связи между классами

**Композиция Game → Board.** Доска — поле-объект по значению внутри партии.
Доска создаётся вместе с партией и уничтожается вместе с ней: если уничтожить
партию, доски больше не существует.

**Агрегация Board → Piece.** Доска хранит указатели на фигуры. Фигуры создаются
снаружи и передаются доске. Если уничтожить доску, фигуры останутся живы — доска
ими не владеет.



Часть 2: C++ (умные указатели)



Во второй части обычные указатели заменены на умные.

В main показана работа трёх видов указателей. unique\_ptr — единственный владелец, объект уничтожается автоматически при выходе из блока, владение передаётся через std::move, после чего исходный указатель пуст. shared\_ptr — несколько владельцев, счётчик use\_count растёт при копировании и уменьшается при уничтожении копии, объект удаляется вместе с последним владельцем. weak\_ptr — наблюдатель, не продлевает жизнь объекту, перед использованием проверяется через lock.



Отдельно показаны массивы. Массив объектов создаётся через std::make\_unique<Piece\[]>, а массив владельцев — это std::unique\_ptr<Piece> arr\[3], где каждый элемент создан через std::make\_unique. Все объекты удаляются автоматически в обратном порядке.
