# Шахматы: консольная игра для двух игроков

## Описание проекта
Проект представляет собой консольное приложение на C++ и C#, позволяющее двум игрокам по очереди делать ходы на стандартной шахматной доске. Программа проверяет правильность ходов, отслеживает взятие фигур, фиксирует шах, мат и пат. Целевая аудитория — пользователи, которым интересна классическая игра в шахматы без физической доски, с автоматическим соблюдением всех правил.

## Игровой процесс
* **Старт:** Игроки садятся за одну консоль и по очереди вводят ходы в текстовом формате (например, `e2-e4`).
* **Проверка хода:** Программа проверяет, что ход допустим для выбранной фигуры, с учётом всех правил: направление движения, длина хода, наличие препятствий на пути, невозможность пойти на клетку со своей фигурой.
* **Отображение доски:** После каждого хода доска перерисовывается в текстовом (ASCII) виде.
* **Особые ситуации:** Программа распознаёт и обрабатывает шах, мат, пат, рокировку, взятие на проходе и превращение пешки.
* **Предупреждения:** Если ход ставит короля под шах — выводится предупреждение, и ход отклоняется.
* **Окончание партии:** При мате или пате игра завершается, объявляется победитель или ничья. Игроки также могут сдаться или предложить ничью по ходу партии.
